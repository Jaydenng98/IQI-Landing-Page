Lock your data to your admin account

You're logging in with your admin account now. One more step makes sure nobody can read enquiries without logging in.

  1. In Supabase, go to Authentication → Sign In / Providers and turn off Allow new users to sign up.
  2. Open admin-security.sql and check the admin list (already set to iqi@madrealty.co).
  3. Paste it into SQL Editor and click Run.
  4. Refresh this page. This message disappears once it's locked.

The landing page keeps working: visitors can still send enquiries and see listings.
